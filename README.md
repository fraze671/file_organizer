# File Organizer

Скрипт для автоматической сортировки файлов по папкам в зависимости от их расширения.

## Возможности

- Сортирует файлы по категориям: Images, Documents, Videos, Other
- Поддерживает передачу пути к папке через аргументы командной строки
- Обрабатывает ошибки (несуществующая папка и т.д.)

## Как запустить

1. Убедитесь, что установлен Python 3.10+
2. Откройте терминал в папке проекта
3. Выполните команду:

```bash
python main.py "путь/к/папке"
